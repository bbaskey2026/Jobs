# JobPulse Web Application (Frontend)

Production-oriented Single Page Application for **JobPulse** — India's verified government and private job alert portal.

## Technology Stack
- **React 18** with TypeScript in strict mode
- **Vite** for fast modern bundling
- **Material UI (MUI)** with custom theme (Midnight Navy, Cobalt Blue, Emerald, Amber)
- **Manrope & Inter** typography for a professional editorial look
- **Formik + Yup** for robust frontend form state and validation
- **TanStack Query (v5)** for server state caching and optimistic updates
- **Zustand** for client auth and interface preferences
- **Recharts** for real-time visual analytics
- **Vitest & React Testing Library** for automated UI tests

## Available Scripts

```bash
# Install dependencies
npm install

# Start development server with proxy to backend
npm run dev

# Run unit and component tests
npm test

# Type check
npm run lint

# Build production bundle
npm run build
```
