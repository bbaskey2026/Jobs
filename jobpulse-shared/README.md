# @jobpulse/shared

Independent shared TypeScript library for the JobPulse Government & Private Jobs platform in India.

## Features
- **Enums**: User roles, job sectors, statuses, employment types, alert frequencies, channels.
- **Constants**: Indian states & UTs, central recruitment bodies, pay scales, qualification brackets.
- **Errors**: Standardized error codes and error payload definitions.
- **Types**: Unified domain models, pagination interfaces, DTOs.
- **Contracts**: Typed request and response interfaces for API communication.

## Installation & Build
```bash
npm install
npm run build
```

## Running Tests / Typecheck
```bash
npm run lint
```
